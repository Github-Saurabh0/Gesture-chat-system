Talking to a computer using hand gestures

What if you could chat with a computer… without touching a keyboard?

So I built a Gesture Controlled Chatting System using AI + Computer Vision

Using just hand gestures, the system can:
Detect hand movements in real time
Recognize gestures through webcam
Convert gestures into messages like “HELLO”, “HI”, “YES” and “STOP”
Track hand landmarks using MediaPipe & OpenCV

The craziest part?
Everything happens LIVE through the camera 

This started as a small experiment…
but now I’m planning to turn it into:

Full ASL (American Sign Language) typing
Gesture-based Google search
WhatsApp message automation
AI virtual keyboard
Touchless communication system

Tech Stack:
Python
OpenCV
MediaPipe
Computer Vision

Still improving the gesture accuracy, but seeing AI understand my hand gestures in real time felt insane

Would love to hear suggestions for new features
